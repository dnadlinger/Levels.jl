# [Level structure in a static field](@id reference-structure)

An [`Eigenstructure`](@ref) solves the static hyperfine + Zeeman problem for a
species and a selected basis. The accessors below expose its energies,
eigenvectors and operators. [Bases and representations](@ref bases) explains
their index spaces and gives examples of manual operators and projections.
