# [Rabi frequencies and coupling strengths](@id reference-rates)

Transition amplitudes combine angular-momentum factors with beam geometry;
Rabi frequencies add the intensity and the strength from the Einstein A
coefficient. Species forms use zero-field states; structure forms include
field-induced hyperfine mixing. See [Bases and representations](@ref bases)
for matrix ordering and selection of ``F`` labels.
