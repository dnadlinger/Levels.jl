# [Atomic data](@id reference-species-data)

Level structure data for the supported species — ⁸⁸Sr⁺ ([`sr88`](@ref)), ⁴⁰Ca⁺
([`ca40`](@ref)), ⁴³Ca⁺ ([`ca43`](@ref)) and ¹³⁸Ba⁺ ([`ba138`](@ref)) — with literature
citations for every value. The Ca⁺ isotopes share rate and g-factor measurements from
⁴⁰Ca⁺ and a common polarisability model; masses, level energies and hyperfine data are
specified per isotope.
