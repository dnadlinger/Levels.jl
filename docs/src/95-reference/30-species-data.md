# [Atomic data](@id reference-species-data)

Level structure data for the supported species — ⁸⁸Sr⁺ ([`sr88`](@ref)), ⁴⁰Ca⁺
([`ca40`](@ref)) and ⁴³Ca⁺ ([`ca43`](@ref)) — with literature citations for every
value. The Ca⁺ isotopes share their (⁴⁰Ca⁺-measured) rate, g-factor and
polarisability tables; only masses and level energies are per isotope.
