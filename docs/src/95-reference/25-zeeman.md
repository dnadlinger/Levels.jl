# [Zeeman structure](@id reference-zeeman)

Landé g-factors (LS coupling with the reduced-mass correction to the orbital
g-factor), first-order Zeeman shifts of individual states, magnetic-field
sensitivities of transitions, and the Zeeman Hamiltonian for an arbitrary field
direction.

Frequencies are angular throughout.
