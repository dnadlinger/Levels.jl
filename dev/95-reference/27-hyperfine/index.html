Hyperfine structure

For a species with nuclear spin $I$, each fine-structure level of angular momentum $J$ splits into levels $F = |I-J|, …, I+J$. The HyperfineConstants determine their zero-field energies through hyperfine_shift. StateBasis(species, "S_1/2", "D_5/2") expands both manifolds into all their $|F, m_F⟩$ states.

The nuclear g-factor is the signed value $g_I = μ_I/(I μ_N)$, so the Zeeman Hamiltonian is $H_Z = B (g_J μ_B J_z - g_I μ_N I_z)$, with $J_z$ and $I_z$ in units of $ħ$. The species data uses the effective nuclear moment in the ion, without a diamagnetic-shielding correction.

At finite field, $F$ levels mix and $m_F$ remains exact. An Eigenstructure solves the hyperfine + Zeeman Hamiltonian; zeeman_shift and zeeman_sensitivity then evaluate its labelled eigenstates. insensitive_field finds a sensitivity zero within a supplied bracket. Conventions defines the adiabatic labels, electron-first coupling order and eigenvector phases.

Levels.StateBasis — Method
StateBasis(species::HyperfineOneElectronSpecies, levels...)

Creates a hyperfine state basis, expanding any fine-structure level into all its $F$ levels (in order of increasing $F$, each contributing its $2F + 1$ sublevels in order of increasing $m_F$).

This is the canonical coupled basis the manifold solutions of an Eigenstructure are expressed in.

Levels.coupling_transform — Method
coupling_transform(species, fs_level)

Returns the real Clebsch–Gordan matrix $U_{(m_J,m_I),(F,m_F)} = ⟨J m_J; I m_I | F m_F⟩$ for one manifold. Rows use the product order of Levels.moment_operators; columns use StateBasis(species, fs_level). A product-basis operator transforms as $X_c = U^† X_p U$. Nonzero entries satisfy $m_J + m_I = m_F$.

Coupling is electron first, with Condon–Shortley phases. Nuclear-first states differ by $(-1)^{I+J-F}$; see Levels.hyperfine_reduction for the amplitude convention. The product storage order fixes indices independently of this phase choice.

Levels.hyperfine_shift — Method
hyperfine_shift(species, level)

Returns the zero-field hyperfine shift of the given $F$ level relative to the centroid of its fine-structure level, in angular frequency units.

The shift is $E/ħ$, where the Casimir energy for $K = F(F+1) - I(I+1) - J(J+1)$ is

\[E = \frac{A K}{2} + B \, \frac{\frac{3}{2} K (K + 1) - 2 I (I + 1) J (J + 1)} {4 I (2I - 1) J (2J - 1)}\]

(the quadrupole term only for $I, J > 1/2$), with the constants from the species' HyperfineConstants.

source
Levels.insensitive_field — Method
insensitive_field(species, transition::Pair, bracket; abstol = 0u"mT")

Returns a static flux density along ẑ at which the hyperfine transition's magnetic sensitivity vanishes. bracket is a required pair of flux densities whose sensitivities have opposite signs; there is no default because a transition may have several roots.

Each trial builds an Eigenstructure and evaluates the Hellmann–Feynman derivative through zeeman_sensitivity. abstol is the absolute field tolerance of the bracketed root search; zero runs to floating-point resolution. Physical accuracy also depends on the species data.

source

Levels.moment_operators — Method
moment_operators(species, fs_level) -> (; x, y, z)

Returns the magnetic operator $\vec M = (g_J μ_B \vec J - g_I μ_N \vec I)/ħ$ of one fine-structure manifold, in angular-frequency units per flux density, so that the Zeeman Hamiltonian in angular units is $\vec B ⋅ \vec M$. Here $J$ and $I$ are dimensionless angular-momentum matrices.

The product basis is kron(J-space, I-space): electronic projection varies slowest, nuclear projection fastest, both increasing. Use Levels.coupling_transform to express an operator in the coupled basis.
