Zeeman structure

Landé g-factors (LS coupling with the reduced-mass correction to the orbital g-factor, or measured values where a species provides them), the zero-field magnetic-field sensitivities of transitions, and the coupled-basis Zeeman Hamiltonian of a field vector in an arbitrary direction — the building block of perturbing (ac) fields, not of the static working field.

The static field lives in the Eigenstructure: zeeman_shift(s, state) and zeeman_sensitivity(s, pair) evaluate the labelled eigenstates at its field, exactly for both species kinds (for a hyperfine species via the Hellmann–Feynman theorem on the manifold eigenstates; lande_g of an $F$ level returns the low-field $g_F$ that the species form uses).

Frequencies are angular throughout.

Levels.BOHR_MAGNETON — Constant

The Bohr magneton $μ_B = e ħ / (2 m_e)$, from the physical constants built into Unitful.

source
Levels.NUCLEAR_MAGNETON — Constant

The nuclear magneton $μ_N = e ħ / (2 m_p)$.

Levels.lande_g — Method
lande_g(species, level)

Returns the Landé g-factor of the given level.

For a fine-structure level this is $g_J$ — a measured value where the species provides one (its lande_g_overrides), the LS-coupling expression of Levels.ls_lande_g otherwise. For a hyperfine $F$ level it is the low-field $g_F$,

\[g_F = g_J \frac{F(F+1) + J(J+1) - I(I+1)}{2 F (F+1)} - g_I (μ_N/μ_B) \frac{F(F+1) + I(I+1) - J(J+1)}{2 F (F+1)},\]

with $g_I$ in the nuclear-magneton convention of the species; note that at finite field the hyperfine Zeeman effect is nonlinear (cf. zeeman_shift on an Eigenstructure), so $g_F m_F$ is only the $B → 0$ slope.

source
Levels.ls_lande_g — Method

Returns the LS-coupling Landé g-factor for a single electron ($s = 1/2$), using the free-electron spin g-factor (CODATA 2022) and the leading-order reduced-mass correction to the orbital g-factor, $g_L = 1 - m_e/M$ with $M$ the ion mass (any distinction from the nuclear mass is far beyond the accuracy of this leading-order form).

source
Levels.zeeman_hamiltonian — Method
zeeman_hamiltonian(species, basis::StateBasis, b)

Returns the matrix of the Zeeman Hamiltonian of a magnetic field with the Cartesian 3-vector b — $\sum_J g_J (μ_B / ħ) \vec{b} ⋅ \vec{J}$ for a fine-structure species, $\vec{b} ⋅ (g_J μ_B \vec{J} - g_I μ_N \vec{I}) / ħ$ for a hyperfine one — over the given basis in the zero-field (coupled) basis representation, in angular frequency units.

b is a field vector in the laboratory frame with the quantisation axis along ẑ, and must be real for the result to be Hermitian. It is the building block of perturbing fields (the ac drives of Levels.PeriodicDynamics.zeeman_drives), not the static working field, which belongs to an Eigenstructure; zeeman_hamiltonian(s, b) gives the same operator in a structure's field eigenbasis. The result is block-diagonal in the fine-structure levels, with matrix elements constructed per state, so any basis ordering or subset of sublevels is supported; for a hyperfine species it is not diagonal in $F$ (the field mixes $F$ within each manifold while staying diagonal in $m_F$ for a field along ẑ).

Levels.zeeman_sensitivity — Method
zeeman_sensitivity(species, lower::StateSpec => upper::StateSpec)

Returns the zero-field (first-order) magnetic-field sensitivity $χ$ of the transition between the two given states, in angular frequency units per magnetic flux density (e.g. convertible to rad/µs/mT): the slope $(g_u m_u - g_l m_l) μ_B/ħ$ with the Landé factors of lande_g — $g_J$ for fine-structure states, the low-field $g_F$ for hyperfine ones. For a fine-structure species this is exact at any field; for a hyperfine species the sensitivity at a working field is that of the Eigenstructure form.

The pair may be one as produced by state_pairs.
